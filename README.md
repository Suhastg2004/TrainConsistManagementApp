# Train Consist Management App

A repository for building a **Train Consist Management Application**.

## Overview

This project is intended to manage train consists (the arrangement of locomotives and railcars) with features for organizing, tracking, and maintaining consist data.

## Current Status

This repository is currently in an early setup state.

## Repository Structure

At the moment, the repository contains:

- `README.md` – project documentation
- `.gitignore` – ignored file patterns

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Suhastg2004/TrainConsistManagementApp.git
   ```
2. Navigate into the project:
   ```bash
   cd TrainConsistManagementApp
   ```
